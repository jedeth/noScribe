🎯 POUR QUI ?
  ✓ Processeurs Intel (Core, Ultra, Xeon)
  ✓ Transcriptions longues (plusieurs heures)
  ✓ Besoin de vitesse maximum

🚀 INSTALLATION (10 minutes) :

  1. Lancez le script d'installation :
     ./install_openvino.sh

     (Windows : pip install -r environments\requirements_win_cpu.txt)

  2. Configurez pour vitesse optimale :
     python3 configure_for_speed.py

  3. Testez noScribe :
     python3 noScribe.py

     Cherchez dans les logs :
     "🚀 Intel hardware detected - using OpenVINO"

  4. C'est tout ! Profitez du speedup 2-6x 🎉

⚠️  PREMIÈRE TRANSCRIPTION = LENTE (5-10 min)
    Le modèle Whisper est converti en OpenVINO.
    Les transcriptions suivantes seront ultra-rapides !
